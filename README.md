# Webynix 🚀  
### AI Powered Website Builder Platform

Webynix is a modern AI-powered website builder platform that allows users to generate premium responsive websites instantly using natural language prompts.

The platform combines Artificial Intelligence, modern frontend technologies, authentication, payment integration, and real-time website rendering into a single seamless workflow.

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/prashantsingh30/Webynix.git

cd Webynix
```

---

# 🚀 Frontend Setup

```bash
cd client

npm install

npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

# 🚀 Backend Setup

```bash
cd server

npm install

npm run server
```

Backend runs on:

```bash
http://localhost:3000
```

---

# 🔑 Environment Variables

## Frontend `.env`

```env
VITE_API_URL=http://localhost:3000
```

---

## Backend `.env`

```env
DATABASE_URL=your_database_url

STRIPE_SECRET_KEY=your_stripe_secret_key
STRIPE_WEBHOOK_SECRET=your_webhook_secret

GEMINI_API_KEY=your_gemini_api_key
GROQ_API_KEY=your_groq_api_key

BETTER_AUTH_SECRET=your_auth_secret
BETTER_AUTH_URL=http://localhost:3000

TRUSTED_ORIGINS=http://localhost:5173

NODE_ENV=development
```

# 🧠 How Webynix Works

1. User enters website prompt  
2. AI enhances the prompt  
3. Gemini/Groq generates website code  
4. Website preview is rendered instantly  
5. User can revise/edit website  
6. Projects are saved into PostgreSQL  
7. Users can publish websites publicly
